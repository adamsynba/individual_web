# Individual JavaScript DOM Practice (Tasks 6–10)

## How to run
1. Extract `individual_work.zip`.
2. Open `index.html` in a browser or use VS Code Live Server.
3. JavaScript is in `js/script.js`; CSS is in `css/style.css`.
4. Task 8 images are local SVG files in `images/`, so they work offline.

## Included
- Task 6: Increase, Decrease (minimum zero), Reset, one update function.
- Task 7: live preview, character counter, Clear and return focus.
- Task 8: select among three images; update src, alt and caption.
- Task 9: keydown/event.key; Enter displays text; Escape clears input and result.
- Task 10: mouseenter/mouseleave and focus/blur; visible focus indicator.
